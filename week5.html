Race Conditions

What Is a Race Condition?

A race condition occurs when multiple threads access shared data and the outcome depends on execution timing. The result is non-deterministic — correct behaviour relies on a specific (unguaranteed) ordering of operations.

Multithreading

Running multiple threads within one process that share memory and resources. While this improves performance, it introduces the risk of concurrent access to shared state.

Critical Sections

A critical section is a portion of code that accesses shared data and must only be executed by one thread at a time. If two threads enter a critical section simultaneously, data corruption or security vulnerabilities can result.

⏱️

TOCTTOU Attacks

Time-Of-Check To Time-Of-Use

TOCTTOU is a specific class of race condition where a resource changes between the time it's checked and the time it's used.

Program checks file permissions
→
Attacker swaps file with symlink
→
Program writes to /etc/passwd

Classic TOCTTOU Example

// 1. Check: Is the file safe to write?
if (access("/tmp/userfile", W_OK) == 0) {
    // 2. WINDOW: Attacker replaces file with symlink
    //    ln -s /etc/passwd /tmp/userfile
    
    // 3. Use: Write to the file (now /etc/passwd!)
    fd = open("/tmp/userfile", O_WRONLY);
    write(fd, data, len);
}
Impact: The attacker tricks a privileged program into writing to a sensitive system file.

Malware Types

What Is Malware?

Software designed to harm, exploit, or compromise systems. Malware encompasses a broad range of malicious software categories.

Malware Categories

🔴 Virus

Requires a host file and user action to spread. Attaches to legitimate programs.

🟠 Worm

Self-replicates automatically across networks without user interaction.

🟡 Trojan

Malware disguised as legitimate software. User willingly installs it.

🟣 Ransomware

Encrypts files and demands payment for the decryption key.

🔵 Botnet

A network of compromised machines controlled remotely by an attacker (C&C).

⚫ Rootkit

Hides itself by modifying OS internals. Extremely difficult to detect.
